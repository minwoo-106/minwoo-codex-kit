# 검색 노출 기술 검토

사용자가 공개·색인을 원하는 페이지와 의도적으로 비공개인 페이지를 먼저 구분한다. 기존 저장소·URL·공식 검색 도구의 근거로 요청 범위를 점검하며 사이트를 임의로 공개하거나 noindex를 제거하지 않는다.

제목·설명, HTTP 응답, robots와 noindex, 대표 URL의 일관성, 사이트맵, 구조화 데이터, 실제 렌더된 내용의 차이를 확인한다. 필요한 경우 [스냅샷 검사](references/checks.md)를 사용한다. 정적 파일 검사로 검색엔진의 실제 수집·색인·순위를 확인했다고 보고하지 않는다.

누락된 근거와 실제 결함을 구분하고 URL 또는 파일 위치, 관찰한 값의 종류, 영향, 수정안을 제시한다. 자동 검사의 review 항목은 추가 해석이 필요하며 오류와 같지 않다. JSON-LD 문법 통과를 리치 결과 자격·검색 노출의 보장으로 표현하지 않는다.

수정까지 요청되면 기존 라우팅·공개 범위·프로젝트 테스트를 보존하며 수정하고 같은 자료로 재검사한다. UI 미적 평가·접근성·브라우저 동작 검사는 해당 스킬의 별도 역할이다. 이미 허용된 범위에서 진행하며 승인 설정을 변경하지 않는다.
