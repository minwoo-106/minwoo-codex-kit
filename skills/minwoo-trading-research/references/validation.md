# 실험 검증 기준

## 고정 실험 계약

실험 ID, 후보 정의, 변경 축, 입력 해시, 코드 해시, 등록 시각, 시작/종료 시각, 자료 출처, 자본, 수량 규칙, 비용, 체결, 결측 정책을 보존한다. 결과를 본 뒤 임계값을 수정하면 새 후보로 관리한다. 같은 날짜 재실행은 원본 결과와 입력 차이를 추적하고 누적 거래에 중복 합산하지 않는다.

- 배분 실험: 진입/청산은 고정하고 바꾼 위험 예산·종목 한도를 표시한다. 슬롯과 거래당 위험을 함께 바꾸면 분산 배분 묶음 가설로 부른다.
- 일봉/스윙: 당시 확보 가능한 과거 자료만으로 종목군을 정한다. 오늘 살아남은 종목 목록을 과거에 소급하지 않는다. 완료 일봉 다음 거래일 시가 체결을 사용하고 일봉의 고가·저가 도달 순서를 추정하지 않는다.
- 후보 간 비교: 같은 자료에서 시작한 가상 기준선과 비교한다. 실제 계좌는 체결과 운영 중단이 달라 별도 표로 둔다.
- 비용: 명시적 수수료/세금, 슬리피지, 미확인 실제 비용을 구분한다. 완료 거래 비용과 미완료 포지션에 이미 지출된 비용의 범위도 맞춘다.
- 큰 승자: 동일 신호의 수량 변화와 청산 시점 변화를 따로 표시한다. 수익 증가가 단순 규모 확대인지 구분한다.

## 의미 있는 테스트

1. 미래 봉을 바꿔도 그 이전 신호·선정·체결 수량이 바뀌지 않는가.
2. 신호 이전 가격이나 동일 완료봉 종가로 체결하지 않는가.
3. 포지션/예약이 수량·현금·위험·하루 횟수에 중복 또는 누락 반영되지 않는가.
4. 부분익절이 완료 승리 거래로 집계되지 않는가.
5. 후보 탈락 후에도 열린 가상 포지션을 추적하고, 자료가 끊기면 미완료로 표시하는가.
6. 일봉 누락·원주가 불연속·관측 시각 지연을 숨기지 않는가.
7. 연구가 실패하거나 제한시간을 넘겨도 운영 장부·주문·보유분이 바뀌지 않는가.
8. 같은 입력의 재실행 결과가 재현되고, 다른 입력/비용/기간은 비교에서 검출되는가.

작업 범위에 관련된 테스트만 선택한다. 승률을 높이려고 손실을 미실현 상태로 남기거나 좋은 구간만 보고하지 않는다. 정확한 관측이 없으면 장중 최초 보호가 이탈 시각·초 단위 MFE를 만들지 않는다.

## 보고

실제 기록의 원인 집계 → 동일 조건 가상 비교 → 승자 보존/손실/비용 변화 → 결측 및 과최적화 한계 → 다음 검증 순으로 정리한다. 수익률·승률 향상 보장이나 자동 실전 전환으로 마무리하지 않는다. 확실한 결론이 없더라도 이미 배제한 가설, 유망한 후보, 확보할 자료를 구체적으로 남긴다.
