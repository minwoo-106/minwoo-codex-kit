# 스킬 목록 크기 점검

```text
python <스킬>/scripts/skill_inventory.py --root <사용자 스킬 폴더> --root <실제 활성 플러그인 스킬 폴더>
```

읽기 전용이며 SKILL.md 메타데이터와 선택 정책만 집계한다. 이름·설명·경로로 구성한 발견 목록의 문자 수와 UTF-8 바이트 수, 중복 이름, 명시 호출 전용 수를 출력한다. 출력에 개인 절대 경로·설명 본문은 포함하지 않는다. 링크 디렉터리는 따라가지 않고 오류로 남긴다.

기본 비교선 8,000자는 모델 컨텍스트 크기를 모를 때 공식 문서에 나온 대체 기준이다. 실제 모델에서는 기본 2% 토큰 예산 등이 적용되므로 이 숫자를 실제 호스트 제한이나 정확한 토큰 수라고 주장하지 않는다. 전체 cache를 스캔하면 비활성 버전도 포함될 수 있으므로 현재 세션에 제공된 활성 스킬 루트를 지정한다.

초과하면 긴 설명·역할 중복을 검토한다. kit의 이름·발동 단어는 앞부분에 두고 세부 절차를 본문/참고 자료로 옮긴다. 사용자 요청 없이 다른 스킬을 삭제하거나 명시 호출 전용으로 바꾸거나 skills.max_context_tokens·승인 설정을 수정하지 않는다. 실제 노출 누락 여부는 새 세션에서 확인한 목록·경고와 구분해 보고한다.
