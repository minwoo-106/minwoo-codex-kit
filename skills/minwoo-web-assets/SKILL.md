# 웹 자산 준비

실제로 사용할 자산과 해당 화면만 조사한다. 이미지의 역할·화면 표시 크기·원본 크기·바이트 수·대체 텍스트 필요 여부, 폰트 파일·굵기·한글 지원·이용 조건을 확인한다. CSS 배경·SVG·영상·가변 폰트 등 확인하지 못한 형식은 따로 표시한다.

이미 정한 브랜드 방향을 기준으로 사진의 색감·구도·피사체, 일러스트의 선·질감, 아이콘 계열을 정리한다. 모든 사진에 같은 필터를 씌우는 규칙을 만들지 않는다. 자료를 열어보지 않고 파일명만으로 내용·품질·출처를 확정하지 않는다.

[준비·검증 기준](references/preparation.md)에서 필요한 항목만 적용한다. 이미지 생성·편집은 현재 제공되는 이미지 도구와 해당 지침을 따른다. 기존 원본은 보존하고 파생 파일을 구분한다. 폰트·이미지의 공개 URL이나 다운로드 성공은 상업적 사용 허가가 아니다. 출처·라이선스·필요 고지와 미확인 권리를 기록한다.

결과는 자산별 사용 위치·관찰 정보·변경 또는 제안·출처·남은 확인 항목을 정리한 인벤토리다. 실제 수정까지 요청됐으면 필요한 변환을 수행하고 렌더된 결과·화질·전송 크기를 확인한다. 분석 요청에서는 원본을 수정하지 않는다.

설치된 minwoo-browser-check의 inspect_site.mjs가 있으면 브라우저가 실제로 불러온 이미지의 크기·실패 여부를 보조 증거로 쓸 수 있다. 이 도구는 이미지 내용·라이선스·CSS 배경 전체를 판정하지 않는다. 도구가 없으면 기존 브라우저·파일 도구로 같은 사실을 확인한다.
