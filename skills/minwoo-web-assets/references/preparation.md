# 준비·검증 기준

## 용량과 표시

표시 크기·기기 픽셀 비율·잘림 의도를 먼저 정한다. 큰 원본을 단순히 작은 CSS 크기로 표시하면 전송량은 줄지 않는다. 반응형 srcset/sizes, 현대 형식과 호환성 대안을 프로젝트 구성에 맞춰 검토한다. 투명도·선명한 문자·사진의 특성을 구분하고 변환 전후 실제 화면을 비교한다.

첫 화면의 중요한 이미지를 무조건 지연 로딩하지 않는다. 아래쪽 이미지는 필요한 시점에 로딩하고 가로세로 비율을 확보한다. 관찰한 전송 크기 0은 캐시·교차 출처 제한 등일 수 있으므로 파일이 무료라는 뜻으로 해석하지 않는다.

## 폰트와 스타일

필요한 굵기·문자 범위만 사용하되 한글 서브셋 때문에 글자가 빠지지 않는지 대표 문장을 확인한다. 대체 폰트 전환 전후 줄바꿈·레이아웃을 본다. 시스템 폰트로 대체할 수 있는 요청에 외부 폰트를 강제하지 않는다.

사진·아이콘의 통일 기준은 프로젝트 디자인 문서 한 곳에 둔다. 자산 인벤토리는 출처·파일·사용 위치를 연결한다. 공유할 파일에는 개인 경로와 비공개 라이선스 증빙 원문을 복사하지 않는다.
