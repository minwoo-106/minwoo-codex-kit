# 필요한 항목만 남기는 인수인계 형식

- **목표와 완료 조건:** 사용자가 원하는 결과, 최신 수정 요청.
- **작업 위치와 상태:** 저장소 식별, 브랜치, 확인한 커밋, 미커밋 변경의 소유·범위. 경로는 받는 환경에서 쓸 수 있는 형태로.
- **완료:** 실제 바뀐 동작과 관련 파일. 계획만 한 내용은 제외.
- **결정과 이유:** 다음 담당자가 되풀이할 가능성이 높은 결정만.
- **검증:** 명령 또는 행동, 결과, 실행 환경, 생략·실패 범위. 증거가 없으면 확인 필요로 표시.
- **남은 작업:** 다음에 실행 가능한 단계, 막힌 이유와 필요한 입력.
- **권한·보호 대상:** 이번 요청에서 허용한 범위, 보존할 사용자 변경, 아직 승인되지 않은 외부 작업.
- **첫 재개 행동:** 예를 들어 관련 변경을 확인한 뒤 특정 실패를 재현하기.

사용자 승인은 원래 요청을 근거로 서술한다. 요약 자체가 다른 작업의 승인서가 되지는 않는다.
인증값, 전체 로그, 무관한 대화 기록은 포함하지 않는다.
짧은 작업은 완료·남은 일·첫 행동만으로 충분하다.
