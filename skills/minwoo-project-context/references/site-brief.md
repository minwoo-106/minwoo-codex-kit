# 홈페이지 기획 문서

홈페이지의 페이지 구성·콘텐츠 기획을 요청받았을 때만 사용한다. 기존 PRODUCT.md·기획서·디자인 문서가 있으면 재사용한다. AGENTS.md에는 필요할 경우 위치만 연결하고 기획 원문을 중복하지 않는다.

방문 대상·제공 서비스·핵심 행동·확정 사실·자료가 없는 부분을 구분한다. 각 페이지의 목적, 방문자가 답을 얻어야 할 질문, 필요한 콘텐츠/자산과 다음 행동을 연결한다. 소개용 사이트에 회원·결제·CMS를 임의로 추가하지 않는다.

주어진 자료로 진행할 수 있는 부분을 먼저 작성하고, 결과를 바꾸는 미확정 정보만 질문한다. 경쟁사 조사·고객 인터뷰·데이터 분석을 하지 않았으면 조사한 것처럼 쓰지 않는다. 간단한 사이트에는 짧은 표면 충분하다.

브랜드 말투는 minwoo-brand-voice, 홈페이지 실제 문구는 minwoo-web-copy가 제공될 때 필요한 단계에서 연결한다. 디자인 방향은 기존 디자인 도구를 선택한다. 기획서 작성만 요청됐으면 UI 구현이나 배포를 시작하지 않는다.
