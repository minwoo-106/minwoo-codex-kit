# 말투 검토

- 서로 다른 사람이 가이드를 읽고도 호칭·용어·문장 태도를 비슷하게 선택할 수 있는지 예문으로 확인한다.
- 소개, 버튼, 오류, 완료 안내의 예문을 비교한다. 같은 표현을 복사하는 것이 아니라 같은 사실과 이름을 유지한다.
- 사용자가 요청한 말투가 이 가이드보다 우선한다. 기존 브랜드를 'AI답지 않게'라는 이유만으로 바꾸지 않는다.
- 주장에는 확인한 근거를 연결한다. 미확인 이용자 수·수상·보증·최상급 표현을 그럴듯한 문구로 채우지 않는다.
- 독자 반응·매출·전환 개선은 별도 조사나 측정이 없으면 가설이다. 모델의 자체 평가를 사용자 테스트라고 부르지 않는다.

독자적인 kit 지침이며 외부 스킬 본문을 복제하지 않았다.
