# 브랜드 말투

기존 브랜드 문서와 실제 서비스 사실, 독자, 사용자가 좋아하거나 피하고 싶은 표현에서 시작한다. 이미 정한 이름·호칭·용어를 보존한다. 근거가 없으면 임시 방향임을 표시하고 독자나 시장 반응을 지어내지 않는다.

말투를 '친근하고 전문적' 같은 형용사로 끝내지 않는다. 독자 호칭, 존댓말 수준, 문장 길이의 경향, 어려운 용어를 설명하는 방식, 유머가 맞는 상황을 실제 문장 쌍으로 보여준다. 숫자 제한을 모든 화면에 강제하지 않는다. 금지어 목록보다 피하는 이유와 대체 표현이 유용하다.

브랜드의 일관된 성격과 상황에 따른 어조를 구분한다. 소개 문구의 활기찬 톤을 결제 실패·개인정보·사과 상황까지 강제하지 않는다. 오류에서는 원인·다음 행동을 분명히 하고 책임을 사용자에게 떠넘기지 않는다.

결과는 기존 브랜드 문서에 반영하거나 요청한 형식의 짧은 말투 가이드로 만든다. 핵심 원칙, 사용/회피 예, 상황별 변화, 확정 사실과 미확정 주장을 구분한다. 일반 AGENTS.md에 브랜드 원문 전체를 넣지 않는다. 승인된 문구 수정은 수행하되 브랜드 작업만으로 게시·발송·계정 변경을 하지 않는다.

홈페이지 본문 작성은 minwoo-web-copy가 제공되는 경우 필요한 단계에서 이어간다. 단순 문구 수정 때문에 새 말투 체계를 만들지 않는다. [평가 기준](references/review.md)은 가이드 작성·일관성 검토 때 읽는다.
