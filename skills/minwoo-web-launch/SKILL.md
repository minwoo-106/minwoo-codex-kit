# 홈페이지 출시 점검

대상 환경·확인할 URL/경로·공개 의도·중요한 사용자 동작을 고정한다. 미리보기·운영 환경과 실제 배포 커밋을 구분하고 관찰한 환경만 보고한다. 모든 프로젝트에 동일한 검사 목록을 강제하지 않는다.

[출시 기준](references/launch.md)에 따라 링크·직접 경로 접속·공유 정보·실제 폼·롤백 준비 중 현재 사이트에 해당하는 것만 확인한다. 관찰할 수 없는 항목은 미확인으로 남긴다. 단순 200 응답을 기능 정상이나 공개 준비 완료로 단정하지 않는다.

minwoo-browser-check의 inspect_site.mjs가 설치돼 있으면 명시한 경로와 제한된 내부 링크의 HTTP 상태를 확인하는 보조 도구로 쓴다. 실행 방법은 그 스킬의 references/site-inspection.md를 읽는다. 설치되지 않았으면 현재 브라우저·HTTP 도구로 필요한 범위를 확인한다. SEO·접근성·보안 검사는 해당 목적의 요청이나 구체적인 우려가 있을 때만 연결한다.

결과에는 대상·시점·환경, 관찰한 결함과 근거, 공개를 막는 사항, 미확인 사항을 구분한다. 검사 완료와 배포 완료를 구분한다. 이미 허용된 배포가 별도 범위에 포함돼 있으면 해당 서비스 도구로 진행하되 이 스킬 자체로 배포·DNS·분석 추적·유료 플랜 변경 권한을 만들지 않는다. 기존 승인 방식을 바꾸지 않는다.
