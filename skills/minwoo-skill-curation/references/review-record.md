# 검토 항목

각 후보에 필요한 만큼 아래 정보를 남긴다. 확인하지 못한 칸은 추정해서 채우지 않는다.

| 항목 | 기록 기준 |
| --- | --- |
| 이름·동일성 | 호출 이름, 저장 폴더, 원본 소유자, 중복 또는 이름 변경 여부 |
| 사용 근거 | 원문 로딩 / 실행 / 부분 사용 / 요약만 / 언급만, 확인 범위 |
| 출처 | 실제 확인한 파일 링크와 커밋 또는 배포 버전 |
| 공개 조건 | LICENSE·NOTICE 위치, 복제 여부, 확인하지 못한 조건 |
| 실행 조건 | 스크립트·참고 자료, 실행 환경, 플랫폼 경로, 인증·외부 접속 |
| 동작 차이 | 승인 질문, 자동 실행·다운로드·저장, 기존 스킬과 겹치는 발동 조건 |
| 편입 형태 | 직접 배포 / 외부 참고 / 환경 제공 / 보류와 그 이유 |
| 검증 | 실제 실행한 대표 작업과 결과, 실행하지 않은 범위 |

원본 버전이 바뀌면 본문의 차이만 보지 말고 새 실행 파일·의존성·라이선스도 비교한다.
부분 사용은 전체 절차 검증으로 승격하지 않는다.
진단 출력이나 스크린샷이 포함된 보고서는 비밀값을 제거한 후에도 공개 필요성이 있는지 판단한다.
직접 작성한 후보는 단순 안내 문서로 충분한지, 반복 실행할 코드가 필요한지부터 구분한다.
