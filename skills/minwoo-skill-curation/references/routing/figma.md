# Figma 선택

현재 노출된 figma 도구와 스킬을 사용한다. 파일 접근 권한과 실제 선택 대상을 확인하며, 아래 이름만으로 도구 이용 가능성을 단정하지 않는다.

| 요청 | 필요한 스킬 |
| --- | --- |
| Figma 도구 공통 실행 | figma:figma-use |
| 새 Design·FigJam·Slides 파일 | figma:figma-create-new-file |
| Figma 디자인을 코드로 구현, get_design_context | figma:figma-design-to-code |
| HTML·프로젝트를 편집 가능한 Design 또는 실행 가능한 Code로 가져오기 | figma:figma-code-workflows |
| 페이지·앱 화면을 Figma 디자인으로 만들기 | figma:figma-generate-design |
| 디자인 토큰·컴포넌트 라이브러리 | figma:figma-generate-library |
| 실제 코드와 Figma 컴포넌트 매핑 | figma:figma-code-connect |
| FigJam 작업 / 다이어그램 생성 | figma:figma-use-figjam / figma:figma-generate-diagram |
| Figma Slides 작업 | figma:figma-use-slides |
| Figma 사양 문서·PRD·RFC | figma:figma-spec |
| Figma 안의 모션 편집 / 코드에 모션 구현 | figma:figma-use-motion / figma:figma-implement-motion |
| 셰이더 / 생성 플러그인 제작 | figma:figma-shaders / figma:figma-generative-plugins |
| Swift·SwiftUI·iOS와 디자인 간 변환 | figma:figma-swiftui |

슬래시는 대체 관계 또는 목적 분기다. 관련 없는 두 스킬을 함께 적용하라는 뜻이 아니다.
공통 figma-use, 새 파일, 다이어그램, 셰이더 등은 해당 도구의 필수 선행 절차를 보존한다. 주도 스킬 하나라는 기본값이 필수 선행 스킬을 생략할 근거는 아니다.
시안을 구현할 때는 그 디자인과 컴포넌트를 기준으로 한다. 새 브랜드 방향을 만드는 스킬로 시안을 임의 재해석하지 않는다.
Figma Slides가 지정됐으면 일반 발표 자료를 새 Spaces 문서로 옮기지 않는다.
