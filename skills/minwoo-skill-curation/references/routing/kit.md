# kit와 작업 관리 선택

| 요청 | 선택 |
| --- | --- |
| 프로젝트별 AGENTS.md 신규 작성·현재 코드에 맞춘 갱신 | minwoo-project-context |
| 다른 채팅·다음 세션으로 작업 인계 또는 재개 | minwoo-work-handoff |
| 확정 커밋·태그 범위의 사용자용 변경 기록 | minwoo-release-notes |
| 공개·업로드 전 민감정보·출처·배포 범위 점검 | minwoo-publication-review |
| 스킬 후보·중복·선택 안내의 검수와 정리 | minwoo-skill-curation |
| kit 설치 차이·목록 크기·선택 갱신 | minwoo-kit-maintenance |
| 스킬 자체의 신규 작성·수정 | skill-creator |
| 검토한 스킬의 설치·설치 후보 확인 | skill-installer |
| Codex 설정·OpenAI 제품의 실제 동작·공식 규격 | openai-docs |
| 플러그인 검색·연결·권한 조회·요청된 관리 | plugin-management:plugin-management |

규칙 작성·인수인계·릴리스 노트는 시간 범위와 독자가 다르다. 진행 상황을 모두 AGENTS.md에 쌓지 않는다.
스킬 검수는 선택 기준과 출처를, 생성은 실제 SKILL.md 품질을, 설치는 파일 배치를, 유지보수는 로컬 수정 보존·차이 검증을 맡는다. 일반 업무를 할 때마다 이 관리 스킬을 읽지 않는다.
명시 호출 전용·내부 보조 스킬은 현재 제공된 호출 정책과 부모 스킬의 필요를 따른다. 분류를 위해 자동 선택을 켜거나 비활성화하지 않는다.

Codex 채팅·프로젝트·작업 트리·사이드바·자동화 관리는 현재 앱 도구를 사용한다. 새 채팅 생성·다른 채팅으로 메시지 전송·예약 작업은 해당 사용자 요청 범위에서만 한다.
일반 스킬 선택에 새 채팅이나 자동화를 만들지 않는다. 스킬 선택 정책은 권한 설정을 바꾸는 기능이 아니다.

## 안내 갱신

이 안내는 스킬 폴더의 references에 함께 설치되며 플러그인 원문을 복제하지 않는다.
새 이름을 추가하거나 설명을 바꾸면 해당 분야에서 기존 역할과 겹치는지, 실제 세션에 도구가 있는지 확인한다.
설치 프로필은 설치 묶음이고 이 안내는 작업 선택 기준이다. 프로필 전체를 동시에 실행하지 않는다.
삭제·이동·플러그인 갱신은 별도 범위이며 안내 정리만으로 실행하지 않는다.
