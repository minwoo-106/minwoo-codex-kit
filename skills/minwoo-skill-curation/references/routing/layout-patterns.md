# 콘텐츠에 맞는 화면 배치

| 표현 | 적합한 화면 | 설계할 때 결정할 것 |
| --- | --- | --- |
| 히어로 섹션 | 신제품의 첫 소개 영역 | 첫 화면에 남길 메시지와 가장 중요한 행동 하나 |
| 벤토 그리드 | 중요도가 다른 소수의 기능 소개 | 가장 큰 칸의 이유와 좁은 화면에서 먼저 읽을 항목 |
| 스플릿 화면 | 제품 사진과 구매 정보의 짝 | 두 열이 한 열이 될 때 사진·정보·구매 버튼의 순서 |
| 카드 그리드 | 같은 기준으로 비교할 상품 목록 | 카드마다 가격·이름의 위치 통일, 긴 상품명의 줄바꿈 |
| 사이드바 | 여러 화면을 오가는 업무 도구 | 작은 화면에서 메뉴를 열고 현재 위치로 돌아오는 동작 |
| 매거진형 | 대표 기사와 관련 기사를 함께 편집 | 대표 글과 보조 글의 위계, 한 열에서도 이어지는 독서 순서 |
| 대시보드 | 지표를 보고 조치하는 운영 화면 | 중요한 지표·기간·다음 행동, 데이터가 없을 때의 표시 |
| Z 패턴 | 글이 적고 시선 이동이 단순한 소개 화면 | 핵심 내용이 시각적 동선 없이도 문서 순서로 이해되는지 |
| 풀블리드 | 사진을 화면 가장자리까지 펼치는 브랜드 페이지 | 글의 대비와 모바일에서 잘리는 피사체 위치 |

같은 제품 상세 페이지에서도 첫 영역은 히어로, 넓은 화면은 사진과 구매 정보의 스플릿, 아래의 관련 상품은 카드 그리드로 조합할 수 있다. 이미 참고 화면이나 디자인 시스템이 정해졌으면 해당 구조를 우선한다.
