# 홈페이지 디자인·문구 보강 선택

웹 작업 중 아래 요구가 있을 때만 해당 절을 읽는다. 이 문서는 별도 디자인 체계나 전체 필수 검사 목록이 아니다.

## 방향 비교

21st-ui-explore 또는 현재 사용자가 지정한 디자인 도구로, 같은 사실·기능을 유지한 서로 다른 방향을 비교한다. 색만 바꾼 안을 다른 전략이라고 표현하지 않는다. 대상·콘텐츠 밀도·주된 이미지·타이포그래피·탐색 구조의 차이와 적합한 이유를 설명한다. 선택된 디자인의 근거를 기존 디자인 문서 한 곳에 남긴다.

## 한글 화면

기존 UI 개선은 impeccable, 새 시각 방향은 선택한 디자인 스킬이 주도한다. 실제 글꼴·굵기·한글 지원, 좁은 모바일에서 제목과 숫자·단위·버튼이 끊기는 위치를 렌더링으로 확인한다. 한글에 영문 기준 글자 수·자간·대문자 규칙을 그대로 강제하지 않는다. 줄바꿈을 고정하는 br·nowrap이 다른 크기에서 잘림을 만들지 않는지 본다.

## UI 문구

버튼·오류·빈 상태·완료 문구는 impeccable의 해당 기능을 우선한다. 홈페이지 판매·설명 본문은 minwoo-web-copy, 채널 전체의 말투 체계는 minwoo-brand-voice를 선택한다. 같은 버튼이 단계마다 다른 행동 이름으로 바뀌지 않게 하고 문의 접수·예약 확정·결제 성공을 구분한다. 검증되지 않은 처리 성공을 문구로 덮지 않는다.

## 이미지와 표현

자산의 출처·용량·표시 크기·스타일 준비는 minwoo-web-assets가 맡고, 실제 이미지 생성·편집은 제공된 imagegen 또는 사용자가 지정한 도구를 사용한다. 이미지 스타일 방향을 매 이미지마다 다시 정하지 않는다. 생성된 이미지가 실제 상품·현장·고객 후기라고 오해되게 설명하지 않는다.

이 기능들을 문구 한 줄 수정에 모두 적용하지 않는다. 모델 자체 검토와 실제 사용자 반응·전환 실험 결과를 구분한다.
