# 스킬 수집·검수

자료를 많이 모으는 것보다 다음 작업에서 믿고 선택할 수 있는 목록을 만든다.

작업별 역할·겹침을 정리할 때 [선택 안내](references/routing.md)의 해당 분야 문서를 갱신한다. 일반 업무에서는 전역 지침의 진입점으로 해당 참고 문서만 읽을 수 있으며 이 검수 절차 전체를 적용하지 않는다. 선택 안내의 관리 원칙은 [kit와 작업 관리](references/routing/kit.md)를 따른다.

- 제공받은 대화·파일 범위부터 조사한다. 전체 채팅이나 개인 폴더를 무조건 수집하지 않는다.
- 같은 이름도 원본·버전이 다르면 차이를 확인한다. 이름 변경·폴더명 차이·플러그인 접두사를 기록하되 중복 사용 횟수를 성능 근거로 삼지 않는다.
- 실제 본문 로딩, 도구 실행, 부분 적용, 요약에만 남은 이력, 이름 언급을 구분한다. 사용자의 보고와 직접 확인한 실행 로그를 섞지 않는다.
- 공개 원본의 해당 폴더·참고 파일·확인 커밋·LICENSE/NOTICE를 확인한다. 현재 공개 버전으로 과거 설치 출처를 역추정하지 않는다.
- 본문뿐 아니라 실행기·데이터·플랫폼 경로·로그인·네트워크·다운로드와 사용자 확인 요구를 검토한다. 원문이 요구하는 절차와 실제 사용자의 승인 범위를 함께 고려하며 승인 모드를 바꾸지 않는다.
- 기존 스킬과 같은 역할이면 기존 것을 유지하거나 선택 기준을 정리한다. 직접 배포, 외부 원본 참고, 환경 제공 기능, 의존성이 빠진 후보 중 맞는 형태를 고른다.
- 설치·실행·원문 재배포는 목록 편입과 별개다. 요청이 편입까지 포함하면 필요한 변경을 수행하되, 외부 원문을 복제할 때는 재배포 조건을 충족한다. 라이선스가 없으면 허용된 것으로 간주하지 않는다.

출력 항목과 갱신 기준은 [검토 항목](references/review-record.md)을 사용한다.
kit 저장소가 지정되면 기존 카탈로그를 갱신하고 오래된 숫자·링크·미검증 표시도 맞춘다.
일회성 검토라면 짧은 표로 끝낸다. 대화 원문·회사 자료·개인 경로는 공개 결과에서 제외한다.
