# 로컬 영상 비교·검토

기존 프로젝트에 전용 검토 도구와 지침이 있으면 먼저 확인한다.
이 스킬은 전용 도구가 없는 프로젝트에서 사용할 수 있는 독립적인 비교 도구다.
기존 studio-review의 프로젝트 설정이나 파일을 바꾸지 않는다.

납품 파일의 기술 규격 점검 요청이면 [납품 점검](references/delivery.md)만 읽고 진행한다. 아래 두 영상 비교 절차는 비교 요청에서 사용한다.

1. 비교할 영상 두 개와 같은 컷 ID의 버전별 시작·종료 시간을 확보한다. 영상 길이가 달라졌다면 전체 타임라인의 같은 시간을 같은 장면으로 가정하지 않는다.
2. [설정·실행 안내](references/usage.md)에 따라 로컬 설정을 만든다. 경로가 불명확하면 필요한 파일 위치만 확인한다. 원본 영상은 수정하지 않는다.
3. 설정 검사 후 읽기 전용 로컬 서버를 실행한다. 이 작업에서 이미 시작한 서버가 있고 review.json의 설정·영상 해시가 같으면 재사용한다. 다른 작업의 서버를 임의로 종료하거나 재사용하지 않는다.
4. 실제 화면에서 컷 선택·재생·메모 내보내기를 확인한다. 기술적 재생 성공, 직접 본 화면, 직접 들은 소리, 사용자의 판단을 구분한다.
5. 내보낸 메모를 --check-notes로 검증한다. 영상·설정이 바뀌었거나 컷과 시간이 맞지 않으면 이전 메모를 최신 영상의 검토 결과로 사용하지 않는다.

화면은 컷별 시작점을 맞춰 재생하며 프레임 단위 동기화나 자동 품질 판정을 하지 않는다.
소리는 기본 음소거이고 선택한 한 버전만 들린다. 실제로 듣지 않았다면 청취했다고 쓰지 않는다.
메모는 브라우저에서 JSON으로 내보내야 저장된다. 서버는 원본·설정·메모를 쓰지 않는다.
완료 시 사용 중인 화면이면 서버를 유지하고 실행 위치를 알려준다. 검증용 서버는 검증 후 종료한다.
