# 설정과 실행

Python 3.10 이상과 HTML video를 지원하는 데스크톱 브라우저가 필요하다. 외부 Python 패키지는 필요 없다.
MP4·WebM·OGV 확장자를 허용하지만 실제 코덱 재생 가능 여부는 브라우저에 달려 있다.

설정 파일 예시는 다음과 같다. **실제 영상과 확인한 컷 구간으로 바꾼 뒤** 실행한다.
file은 설정 파일 기준 상대 경로나 명시적인 절대 경로를 받는다. 링크·정션은 허용하지 않는다.

```json
{
  "schema": 1,
  "title": "오프닝 비교",
  "versions": [
    {"id": "before", "label": "수정 전", "file": "before.webm"},
    {"id": "after", "label": "수정 후", "file": "after.webm"}
  ],
  "cuts": [
    {"id": "opening", "label": "오프닝", "ranges": {"before": [0, 2], "after": [0.5, 2.5]}}
  ]
}
```

두 버전의 id는 서로 달라야 한다. 컷은 1~200개이며 모든 컷에 두 버전의 구간이 있어야 한다.
시간은 초 단위이고 0 <= 시작 < 종료다. 실제 길이를 넘는 구간은 화면에서 재생을 막고 수정 안내를 표시한다.

```text
python <스킬 폴더>/scripts/serve_review.py --config <설정.json> --check-config
python <스킬 폴더>/scripts/serve_review.py --config <설정.json>
python <스킬 폴더>/scripts/serve_review.py --config <설정.json> --check-notes <내보낸 메모.json>
```

서버가 출력한 127.0.0.1 주소를 연다. 포트는 기본적으로 빈 포트를 선택하며 --port로 지정할 수도 있다.
링크는 실행마다 바뀌고 검토 파일에 접근하는 토큰을 포함하므로 공개 문서에 남기지 않는다.
서버는 루프백에서만 듣고 설정에 지정한 영상과 도구의 정적 화면만 제공한다. 디렉터리 전체를 공개하지 않는다.
다른 브라우저 사이트에서의 접근을 제한하지만 같은 PC의 악성 프로그램에 대한 보안 경계는 아니다.

## 화면 사용

- 컷을 고른 뒤 비교 재생을 누르면 각 버전의 해당 구간 시작에서 재생한다.
- 반복을 켜면 각 영상이 자신의 구간 끝에서 시작으로 돌아간다. 두 구간 길이가 다르면 반복 주기도 다르다.
- 버전별 재생바로 개별 관찰할 수 있다. 비교 재생은 선택한 컷의 시작으로 돌아간다.
- 소리 선택에서 한 버전만 활성화한다. 기술·화면 관찰·사용자 판단 중 메모 성격을 선택하고 현재 시점에 메모를 추가한다.
- JSON 내보내기로 저장한다. 기존 메모 가져오기는 현재 영상·설정과 맞는 항목만 중복을 제거해 추가한다.
- 저장하지 않은 메모가 있는 동안 창을 닫으면 브라우저가 이탈 확인을 표시할 수 있다. 실제 저장 여부는 다운로드 파일로 확인한다.

## 메모와 변경 감지

메모에는 설정 파일의 SHA-256과 두 영상의 SHA-256, 컷·버전·영상 시간·메모 종류가 포함된다.
설정의 공백만 바뀌어도 설정 해시가 달라져 기존 메모를 거절한다. 자동으로 새 대상으로 바꿔 끼우지 않는다.
메모에는 사용자가 입력한 내용이 들어가므로 프로젝트의 비공개 위치에서 관리한다.

서버는 시작 시 영상 전체를 해시하므로 큰 파일은 준비 시간이 걸린다.
실행 중 설정·영상의 크기·수정 시각·파일 식별 정보 변경을 감지하면 요청을 거절한다.
파일을 수정했으면 서버를 재시작한다. 같은 크기·시각을 의도적으로 유지한 변조나 악의적인 동시 교체까지 방어하는 도구는 아니다.
메모 검증은 디스크의 현재 영상을 다시 해시한다.

--check-config는 파일 존재·형식·구간 수치·해시를 확인한다. 실제 코덱과 구간 종료 시각은 브라우저에서 검증해야 한다.
메모 검증 통과는 대상 일치를 뜻하며 영상 품질 승인이나 내용의 사실성을 보장하지 않는다.
