# Remotion 자막과 렌더링

프로젝트의 Remotion·React 버전, Composition ID, 길이/fps/해상도, 입력 자료·폰트와 출력 위치를 확인한다. 기존 프로젝트 도구를 우선하며 서로 다른 Remotion 패키지 버전을 섞지 않는다.

1. 기존 SRT는 `@remotion/captions`의 `parseSrt`로 파싱한다. ms→frame 변환, 영상 기준 시간 오프셋, 겹친 자막, 빈 구간, 한글 폰트와 줄바꿈을 확인한다. 비동기 자료는 해당 버전의 렌더 대기 API로 완료를 보장한다.
2. [실행 안내](references/render.md)를 읽고 짧은 구간/대표 프레임부터 렌더한다. 화면에 들어오는 코드는 실행되므로 신뢰하지 못한 원격 프로젝트·외부 URL을 무작정 렌더하지 않는다.
3. 실제 출력의 해상도·fps·길이, 자막이 나타나는/사라지는 시점, 오디오가 있으면 음량·동기화를 확인한다. 조용한 샘플 성공을 실제 오디오 검증으로 보고하지 않는다.
4. 승인된 출력 경로에 최종 렌더하고 결과와 검증 범위를 전달한다. 기존 결과를 덮어쓸 필요가 없으면 새 파일명을 사용한다.

이 스킬은 로컬 렌더링만 담당한다. 전사 모델 다운로드·외부 생성 서비스·유료 렌더링·클라우드 배포는 자동으로 따라오지 않는다. 기존 승인 방식과 요청 범위를 유지한다. 신규 작성 절차이며 공식 API 문서는 실행 안내에 링크했다.
