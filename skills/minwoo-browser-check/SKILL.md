# 웹 동작 검사

접근성의 자동 규칙 검사나 기존 기준 화면과의 차이를 확인하려면 [품질 검사](references/quality.md)를 사용한다. 기능 동작·접근성·화면 비교는 서로 다른 검사이며 필요한 것만 실행한다.

기존 프로젝트의 브라우저 테스트·실행 서버가 있으면 그것을 우선 사용한다. 기대 동작과 대상 환경을 확인하고 실제 DOM·상태·응답을 검증한다. 화면 캡처만으로 기능 통과를 판정하지 않는다.

재사용할 테스트가 없으면 [실행 안내](references/usage.md)의 작은 JSON 시나리오 실행기를 사용한다. 로그인·폼 입력에는 테스트 계정과 합성 데이터를 쓰고, 사용자 프로필·저장된 쿠키를 가져오지 않는다. 승인된 대상에서만 실행하며 실제 결제·발송·운영 데이터 변경은 별도 권한 범위를 따른다.

실패를 재현하는 검사인지 확인한 뒤 수정 후 같은 조건으로 재실행한다. 새 브라우저 컨텍스트, 상태를 기다리는 검사, 명확한 기대 결과를 사용하고 고정 sleep으로 실패를 숨기지 않는다. trace·스크린샷은 민감 데이터가 들어갈 수 있으므로 로컬 증거로 취급한다.

완료 시 시나리오별 결과, 실제 브라우저·환경, 실패 증거와 미검사 범위를 보고한다. 자동 검사가 접근성·디자인·모든 브라우저 지원을 증명하지 않는다.
