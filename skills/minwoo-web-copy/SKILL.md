# 홈페이지 문구

방문 대상, 서비스가 실제 제공하는 것, 페이지의 목적과 다음 행동을 기존 자료에서 확인한다. 이미 있는 말투 가이드는 적용하고 매번 다시 만들지 않는다. 사이트 전체 기획이 필요하면 페이지별 목적부터 정리하되 단순 제목 수정에는 그 절차를 강제하지 않는다.

첫 화면에서 무엇을 누구에게 제공하는지, 왜 살펴볼 만한지, 다음 행동이 무엇인지 읽히게 한다. 기능을 혜택으로 바꿀 때 사실 범위를 넘지 않는다. 결과·기간·가격·무료 여부·후기·고객 수·인증을 지어내지 않는다. 미확정 사실은 질문 또는 작업 메모로 남기고 공개 문구처럼 쓰지 않는다.

페이지마다 방문자의 의문 순서에 맞춰 내용을 구성한다. 장점·근거·절차·FAQ가 모두 필요한 것은 아니다. 실제 사진·사례·상세 설명으로 이미 전달하는 내용을 문구에서 반복하지 않는다. 버튼은 도착 위치나 결과를 예고하고, 비용·가입 등 중요한 조건을 숨기지 않는다.

다른 안을 요청받으면 어순만 바꾸지 말고 강조할 근거·독자 질문·정보 순서가 다른 안을 제시한다. 실제 근거가 더 적은 안을 과장으로 보충하지 않는다. 최종 문구와 선택 이유·확인할 사실을 분리한다.

문구를 화면에 적용하는 작업까지 허용되면 기존 디자인을 사용하고 실제 모바일 줄바꿈·버튼 길이·누락된 상태를 확인한다. 문구 요청만으로 사이트를 새로 만들거나 배포하지 않는다. 상세 검수에는 [화면 문구 기준](references/copy-review.md)을 사용한다. 기술 색인은 minwoo-seo-review, UI 상태별 짧은 문구는 기존 UI 검토 도구가 맡을 수 있다.
