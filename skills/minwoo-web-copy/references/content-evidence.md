# 검색 방문자를 위한 콘텐츠 근거

홈페이지 콘텐츠를 검색 의도에 맞춰 작성·개편할 때만 사용한다. 일반 제목 수정에 전체 SEO 조사를 붙이지 않는다.

- 방문자가 해결하려는 질문과 페이지의 실제 답을 연결한다. 검색량·경쟁도는 관찰 자료가 있을 때만 수치로 적는다.
- 작성 주체, 정보가 만들어진 과정, 사용자가 얻는 결과를 실제 근거로 설명한다. 관련 경험·자격·통계·후기를 창작하지 않는다. 모든 페이지에 가짜 작성자 소개나 불필요한 저자란을 넣지 않는다.
- 사용자가 결정하는 데 필요한 조건·제약·비교·절차를 확인한다. 고정 글자 수·키워드 밀도·FAQ 개수를 목표로 늘리지 않는다. 날짜만 바꾸어 최신 정보인 것처럼 보이게 하지 않는다.
- 제안 문구와 확인할 사실을 구분한다. 서비스 제공 지역·가격·운영 시간·상품 여부가 확인되지 않으면 지역별/상품별 페이지를 대량 생성하지 않는다.
- 자체 콘텐츠 점수는 편집용 기준일 뿐 실제 검색엔진의 E-E-A-T 점수나 AI 인용 확률이 아니다. AI가 쓴 글인지 단정하거나 탐지기 회피·유니코드 일괄 삭제를 품질 기준으로 쓰지 않는다.
- 최종 확인은 원본 사실 보존, 질문에 대한 답, 조건의 정확성, 링크·행동 유도의 실제 도착점으로 한다. 기술 색인/구조화 데이터는 minwoo-seo-review가 맡는다.

[Google 사람 중심 콘텐츠](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)를 근거로 직접 작성했다. [Claude SEO content](https://github.com/AgriciDaniel/claude-seo/blob/6be93f45064ffbadced572b5d5c95f55fd263af0/skills/seo-content/SKILL.md)의 역할 분리를 참고했으며 원문의 점수표·분량 기준·문체 정리 도구는 복제하지 않았다.
