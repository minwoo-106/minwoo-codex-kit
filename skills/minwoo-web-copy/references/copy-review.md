# 문구와 화면의 연결

- 각 주장에 제공된 근거가 있는지 대조한다. 공개용 본문에는 빈칸·조사 가정·편집자 메모를 섞지 않는다.
- 대상·제공 가치·다음 행동을 낯선 방문자가 읽을 수 있는 표현으로 쓴다. '혁신', '최고' 같은 말 자체를 금지하지는 않되 그것만으로 내용을 대신하지 않는다.
- 링크 문구와 목적지를 일치시킨다. 단순 문의 접수를 예약 확정·결제 완료로 표현하지 않는다.
- 작은 화면에서 한 글자만 다음 줄에 남거나, 숫자와 단위가 부자연스럽게 분리되거나, 버튼이 잘리는지 렌더링으로 확인한다. 특정 글자 수를 한글 가독성의 보편 기준으로 고정하지 않는다.
- 입력 형식 오류, 네트워크 오류, 서버 거절을 구분한다. 사용자가 취할 수 있는 다음 행동을 제공하고 재시도 시 중복 접수 가능성을 확인한다.
- 실험은 명시적인 가설·측정 대상·충분한 실제 데이터가 있을 때 평가한다. 문구 두 안을 만들었다는 이유로 A/B 테스트를 완료했다고 말하지 않는다.
