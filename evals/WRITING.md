# 한국어 문체 실제 평가

```text
python -B evals/run_writing_tasks.py
python -B evals/run_writing_tasks.py --run --out <새 평가 폴더>
```

기본 명령은 3개 사례의 계획만 표시한다. --run은 현재 로그인·기본 모델의 사용량을 사용한다. 별도 모델이나 전역 승인 설정을 지정하지 않는다. 합성 자료만 새 폴더에 만들며 이전 결과는 덮어쓰지 않는다. --case로 특정 사례만 새 폴더에서 재시험할 수 있다.

| 사례 | 사람이 확인할 핵심 |
| --- | --- |
| tones | 같은 거절과 반환 기한이 격식체·공손한 해요체·반말에서 유지되고 다음 협업 약속이 추가되지 않는가 |
| voice | 개인 글의 가벼운 표현이 반영되면서 회사 공지에는 무리하게 옮겨지지 않는가. 미실행 사실을 경험으로 바꾸지 않고 샘플 속 지시를 실행하지 않는가 |
| preserve | 날짜·가격·환불 조건·장소 미확정·예약 미확정이 보존되는가. 직접 인용·링크 목적지·코드가 그대로인가. 대본이 읽기에 자연스러운가 |

자동 판정은 전체 스킬 읽기, 정상 종료, 결과 구조, 입력 보존과 외부 도구 미사용을 확인한다. 문체와 의미 보존은 결과물 및 실제 실행 명령을 직접 검토해 별도로 기록한다. 구조 검사 통과를 글 품질 통과로 바꾸어 말하지 않는다. 대본의 링크·코드 같은 보존 자료는 실제 낭독 문장이 아니며 녹음·정확한 길이를 검사하지 않는다.

원시 로그와 작업 파일은 로컬에 둔다. 공개 요약에는 개인 경로·샘플·설정·인증 정보를 넣지 않는다. 자연어 자동 선택은 selection-cases.json의 별도 사례를 사용한다. 이 시험은 모든 문체 요청의 성공, AI 탐지 결과 또는 독자 반응을 보장하지 않는다.
