# 업무 문서 검수와 합성 예제

확인일: 2026-11-13. 기존 형식 제작 도구는 유지하고 [문서 선택 안내](../skills/minwoo-skill-curation/references/routing/documents.md)에 조건부 검수를 연결했다. 사용자 양식·필수 고지를 우선하고, 일반적인 미적 기본값과 구분한다. 전역 규칙에는 문서 신규 작성·서식 개편 시 안내를 읽는 진입 문장만 추가했다.

## 직접 만든 전후 문서

[예제 생성기](document_quality_example.py)는 회사·실명·실제 업무 자료를 사용하지 않는다. 같은 합성 내용으로 반복 머리말·요약 상자·작은 하단 문구·강제 페이지 나눔이 있는 예제와 검수 기준을 적용한 예제를 만든다. **기존 모델과 새 모델의 무작위 A/B 시험이 아니라 의도적으로 설계한 비교 예제**다. 스킬 효과의 통계적 측정이나 AI 작성 판별 결과로 해석하지 않는다.

| 검사 | 수정 전 예제 | 수정 후 예제 |
| --- | --- | --- |
| A4 페이지 수 | 2쪽 | 1쪽 |
| 필수 문구 23개 대조 | 모두 보존 | 모두 보존 |
| 내부 목표일의 제한 조건 | 먼 하단의 7.5pt | 해당 표 아래 11pt 본문 |
| 반복 영문 표제·설명용 하단 문구 | 있음 | 제거 |
| 한글·표·줄바꿈·겹침 | 2쪽 전체 렌더 확인 | 1쪽 전체 렌더 확인 |
| 실제 상태·다음 행동·미확정 조건 | 내용에 존재 | 읽기 흐름에 맞춰 배치 |

본문을 줄여 1쪽을 만든 것이 아니다. 같은 업무·진행 상태·날짜·담당·근거·배포 제한을 보존하고 불필요한 분리와 반복을 없앴다. 이 사례의 1쪽을 모든 보고서의 제한으로 삼지 않는다. 검수 지침에는 지정된 색·로고·결재란·작은 필수 고지를 임의 삭제하지 않는 반대 조건도 명시했다.

재현에는 형식 스킬의 제작 시작 절차와 번들 Python, reportlab·pypdf·pypdfium2, 사용 권한이 있는 한글 TTF가 필요하다. OS 글꼴·PDF·미리보기 이미지는 소스 저장소에 넣지 않는다.

```text
<번들 Python> -B evals/document_quality_example.py --font <한글 TTF> --bold-font <굵은 한글 TTF> --out <저장소 밖 새 출력 폴더>
```

수정 전후 PDF와 모든 PNG를 생성하고 A4 크기·필수 문구 보존을 자동 검사한다. 시각 판단은 실제 PNG를 직접 확인해야 한다. 이번 검수에서 발견한 수정 전 표 제목의 낮은 대비는 수정한 뒤 다시 생성·렌더했다. 최종 예제의 차이는 의도한 편집 기준에 집중한다.

## 실제 안내 선택 시험과 한계

[읽기 전용 시험](run_document_review.py)은 새 보고서, 지정 양식 보존, 단순 추출의 3개 요청을 새 Codex CLI 세션에서 실행한다. 전역 진입점을 통해 필요한 안내를 읽는지 검사한다. PDF 지침 위치는 시험에 제공하므로 형식 도구의 자유로운 발견률 시험은 아니다. 내용상 판단은 자동 읽기 검사와 별도로 검토해야 한다.

```text
python -B evals/run_document_review.py
python -B evals/run_document_review.py --run --out <저장소 밖 새 개인 폴더> --skills-root <설치 스킬 경로> --pdf-skill <PDF SKILL.md 경로>
```

이번 3개 세션은 모두 `registered Core launch requires an installed app` 실행 환경 오류로 필요한 문서를 읽지 못해 실패했다. 새 보고서와 지정 양식 요청에서 문서 안내를 읽으려는 시도는 있었지만 성공한 읽기 증거로 인정하지 않았다. 실패한 도구의 대체 호출도 성공 판정에 포함하지 않았다. 따라서 **자동 선택과 예외 적용의 모델 시험은 미검증**이며, PDF 생성·내용 보존·시각 검수 통과와 구분한다. 승인 설정을 바꾸거나 실행 제한을 해제하지 않았다. 환경 복구 후 같은 명령으로 새 폴더에서 재시험할 수 있다.

## 설치·목록·공개 범위

- 기존 스킬 1개의 참고 안내를 확장했다. 새 스킬 0개, 이름·설명 메타데이터 변경 0개. 원격의 기존 추가분을 포함한 관리 스킬은 33개다.
- PC의 선택 루트 검사: 60개, 자동 선택 후보 54개, 명시 호출 전용 6개, 중복 이름 0개. 표시 문자열 17,028자·UTF-8 21,394바이트로 전후 동일하다. 실제 호스트 토큰 수나 전체 플러그인 목록의 측정은 아니다.
- 임시 설치와 PC 반영 후 반복 실행은 추가 쓰기 0개였다. 문서 안내 3개와 전역 진입 문장만 반영했고, 다른 설치 파일·로컬 규칙 차이를 보존했다. 실행 설정 파일의 전후 해시가 같다.
- 공개 후보는 [검토 기록](../skills/minwoo-skill-curation/references/routing/document-candidates.md)에 출처·범위·충돌을 남겼다. 후보 전체를 설치하거나 실행한 것으로 보고하지 않는다.
- 회사 PDF, 로컬 경로가 담긴 원시 로그, 설치 상태·백업·폰트·인증 자료는 공개 대상에서 제외한다. 공개 범위는 지침·후보 검토·합성 예제 생성기·평가 방법과 정리한 결과다.
