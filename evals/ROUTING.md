# 분야별 선택 안내 평가

이 평가는 설치된 전역 진입 안내에서 필요한 분야 문서와 스킬을 실제로 읽는지 확인한다. 안내 파일 이름이나 기대 스킬 이름은 사례의 요청문에 알려주지 않는다. 실제 서비스 실행·홈페이지 제작·전체 플러그인의 성능 시험은 아니다.

```text
python -B evals/run_routing.py
python -B evals/run_routing.py --run --catalog <개인 catalog.json> --out <새 개인 폴더>
```

기본은 계획 출력뿐이다. --run은 현재 Codex 로그인·기본 모델로 사례마다 별도 읽기 전용 세션을 실행한다. 전역 승인 설정은 수정하지 않는다. catalog.json은 현재 세션에 노출된 스킬의 실제 name을 SKILL.md 절대 경로에 대응시킨 개인 JSON이다. 경로·원문·실행 로그는 공개하지 않는다. 플러그인 접두사와 SKILL.md의 name은 다를 수 있으므로 실제 파일에서 확인한다. 명시 호출 전용 내부 보조 스킬을 자동 선택 후보로 바꾸지 않는다.

평가기준:

- 성공한 명령 출력에 문서 전체가 있어야 읽은 증거로 인정한다. 최종 답변의 이름 언급·실패 명령·부분 읽기는 통과하지 않는다.
- 기대 분야와 필요한 주도 스킬을 읽어야 한다. 필수 선행 스킬·목적이 다른 합리적 보조는 사례별 허용 집합에 명시한다.
- 관계없는 분야나 스킬을 함께 로드하면 실패한다. 단순 계산 사례는 안내·스킬을 로드하지 않아야 한다.
- 현재 catalog 밖에 있는 문서 로딩은 이 평가기의 완전한 감시 대상이 아니다. 원시 기록을 검토해 해석 한계를 남긴다.
- 파일 변경·외부 도구·검색 이벤트를 실패로 판정하고 합성 프로젝트 파일의 불변을 확인한다. CLI 읽기 전용 모드를 사용하지만 모든 셸 명령의 의미를 해석하는 보안 감사 도구는 아니다.
- 첫 실패를 보존하고 원인과 수정 범위를 기록한다. 재시험은 --case로 지정하며 다른 출력 폴더를 사용한다. 성공하도록 기대값을 사후 완화하지 않는다.

공개 결과에는 검토한 summary.json만 넣는다. 결과는 해당 요청·모델·설치 상태에 한정되며 모든 미래 요청의 정확도를 보장하지 않는다.
