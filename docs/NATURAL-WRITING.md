# 자연스러운 한국어와 상황별 말투

`minwoo-natural-writing`은 일반 글·메일·공지·대본의 문체 편집과 제공된 사실에 따른 작성을 맡는다. 내 말투, 격식, 공손함, 편안함, 발화 문체를 한 스킬에서 필요한 만큼 선택한다. 별도 플러그인·유료 서비스·외부 패키지가 필요 없다.

## 사용 예

- “이 초안을 내 글 예시처럼 다듬어줘. 사실과 기한은 그대로 유지해.”
- “이 거절 답장을 예의 있는 해요체로 바꿔줘. 재검토 약속은 추가하지 마.”
- “이 공지를 격식 있는 문체로 정리해줘. 어려운 말로 늘이지 마.”
- “이 설명을 입으로 읽기 좋은 짧은 대본으로 다듬어줘.”

개인 말투는 제공한 예시와 현재 목적을 함께 따른다. 친구에게 쓰는 말투와 공식 메일의 관계를 구분하며 예시가 없으면 그 한계를 인정한다. 개인 글 샘플은 이 저장소에 수집하지 않는다.

## 역할 분리와 설치

브랜드 전체 말투 기준은 `minwoo-brand-voice`, 홈페이지의 설득 구조·문구 작성은 `minwoo-web-copy`가 맡는다. 맞춤법 한 곳을 고치는 요청에는 새 스킬이 필요 없다. 문서 파일 형식·서비스 연결은 기존 문서 플러그인이 담당한다.

documents 묶음과 all 묶음에 포함한다. web에는 홈페이지 문구 스킬이 있으므로 자동 추가하지 않는다. 필요한 환경에서는 개별 선택할 수 있다.

```text
python -B scripts/install.py --skill minwoo-natural-writing --skip-rules --dry-run
python -B scripts/install.py --skill minwoo-natural-writing --skip-rules
```

기존 PC의 스킬 경로가 다르면 README의 `--skills-root` 안내를 따른다. 설치는 승인 설정을 바꾸지 않는다.
