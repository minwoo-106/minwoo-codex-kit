검증일: 2026-10-29. 대상: 0.1.0 배포본.

## 결과

Windows, Python 3.11, PowerShell 7.6 환경에서 **37개 중 36개 통과, 1개 환경 제약으로 생략**.
실패한 검증을 통과로 처리하지 않았으며, 생략 항목은 아래에 구분했다.

```text
python -m unittest discover -s tests -v
Ran 37 tests
OK (skipped=1)
```

현재 제한된 실행 환경의 임시 폴더에서는 파일 교체·Git Bash·정션 생성이 제한되었다.
최종 검증은 짧고 쓰기 가능한 `KIT_TEST_ROOT`를 지정하고 일반 실행 환경에서 격리 테스트로 수행했다.
개인 Codex 설정·규칙·스킬 폴더를 설치 대상으로 사용하지 않았다.

## 추가 확인

- 제공된 전역 AGENTS.md와 비교: 삭제한 문장 0개, 추가한 문장 2개. 기존 11개 영역 보존.
- 두 스킬 모두 제공된 skill-creator의 `quick_validate.py` 검사 통과. 검사에만 필요한 PyYAML은 배포본 밖의 작업 폴더에서 사용했다. 설치기에는 외부 Python 패키지가 필요 없다.
- 두 스킬의 설명과 절차를 수동 검토해 발동 범위를 구분했다. 실제 Codex 모델의 자동 선택에 대한 별도 행동 평가는 수행하지 않았다.
- Python 3.10 문법으로 구문 분석 통과. 실제 실행은 Python 3.11에서 수행했다.
- 현재 배포 파일의 로컬 사용자 경로·주요 토큰 형태·개인키 본문 패턴을 점검했고 발견 사항은 없었다. 직접 작성한 파일과 사용자가 제공한 일반 규칙 외의 회사 자료·기존 스킬은 가져오지 않았다.
- 위 검증은 최초 게시 전에 수행했다. 공개 대상은 이번에 작성한 파일들이며 이전 Git 이력은 없었다.

## 확인하지 않은 범위

Windows PowerShell 5.1 실행 정책을 변경하지 않았다. 해당 환경에서는 README의 Python 진입점을 사용할 수 있다.
네이티브 Linux·macOS 실행, Python 3.10 실제 실행, 개인 전역 경로에 실제 설치한 뒤 새 Codex 세션에서 자동 인식하는 과정은 검증하지 않았다.
Git Bash 통과를 네이티브 Unix 검증으로 간주하지 않는다.

비밀정보 패턴 검사와 수동 검토는 모든 민감정보의 부재를 보장하지 않는다.
공개 범위가 바뀌거나 회사 자료·새 Git 이력이 추가되면 그 범위를 다시 확인한다.
