# 검증 기록

검증일: 2026-10-29. 최신 대상: 0.2.0. 아래 최초 검증 기록은 0.1.0 기준이다.

## 0.2.0 추가 스킬 검증

- 전체 Python 테스트 **50개 중 49개 통과, 1개 생략**. 기존 Windows PowerShell 5.1 실행 정책 제약은 유지했다.
- kit 점검: 일치·차이·누락·추가·중복 분류, 없는 설치 경로를 만들지 않음, 점검 전후 파일 내용·수정 시각 불변 확인.
- 영상 도구: 버전별 컷 구간, 변경된 설정·영상에 대한 메모 거절, 잘못된 수치·ID·메모, 정션 경로 거절 확인.
- 실제 로컬 HTTP 서버: 지정 영상·정적 파일만 제공, 잘못된 토큰·경로·Host·교차 사이트 접근 거절, Range·HEAD 응답, 파일 변경 감지 확인.
- 네 새 스킬을 격리된 폴더에 전체 자원과 함께 설치하고, 기존 전역 규칙·프로젝트 전용 스킬 보존 및 반복 실행 무변경 확인.
- 사용자 요청 범위에서 현재 PC에도 네 스킬의 12개 파일을 설치했다. 원본과 바이트 일치, 반복 설치 무변경, 기존 전역 규칙과 studio-review의 해시 불변을 확인했다. 개인 설치 상태는 공개 저장소에 포함하지 않았다.
- 실제 Edge 브라우저에서 직접 생성한 WebM 두 개로 재생·컷별 반복·컷 전환·구간 끝 정지·음소거 선택 상태·메모 다운로드·가져오기 중복 제거·대상 불일치 거절을 확인.
- 브라우저에서 영상 길이를 넘는 컷의 재생 차단, 실행 중 영상 변경 후 요청·메모 검증 거절 확인. 페이지 JavaScript 오류 없음.
- 1280px 및 390px 폭의 화면 캡처를 확인했고 모바일 가로 넘침이 없었다. 샘플 영상은 무음으로, 실제 청취 검증은 하지 않았다.
- 여섯 SKILL.md의 quick_validate 검사와 스킬 내부 참고 링크 확인 통과. 새 Python 도구는 3.10 문법 검사 통과, 실제 실행은 3.11.

첫 제한 환경 실행에서는 로컬 소켓 연결이 차단되었다. 이후 허용된 실행 환경에서 위 서버·브라우저·설치 테스트를 수행했다.
Playwright는 브라우저 검증에만 사용하며 배포 도구의 실행 의존성이 아니다. 외부 프로젝트 코드·실제 영상·인증 자료는 사용하지 않았다.

스킬의 발동 범위와 인수인계·검수 절차를 수동 검토했다. 독립된 모델 평가나 새 대화에서 자동 선택되는지의 행동 평가는 수행하지 않았다.
네이티브 Linux·macOS, 모든 영상 코덱, 프레임 단위 동기화는 검증 범위에 포함하지 않는다.

## 추가 확인

- 제공된 전역 AGENTS.md와 비교: 삭제한 문장 0개, 추가한 문장 2개. 기존 11개 영역 보존.
- 두 스킬 모두 제공된 skill-creator의 `quick_validate.py` 검사 통과. 검사에만 필요한 PyYAML은 배포본 밖의 작업 폴더에서 사용했다. 설치기에는 외부 Python 패키지가 필요 없다.
- 두 스킬의 설명과 절차를 수동 검토해 발동 범위를 구분했다. 실제 Codex 모델의 자동 선택에 대한 별도 행동 평가는 수행하지 않았다.
- Python 3.10 문법으로 구문 분석 통과. 실제 실행은 Python 3.11에서 수행했다.
- 현재 배포 파일의 로컬 사용자 경로·주요 토큰 형태·개인키 본문 패턴을 점검했고 발견 사항은 없었다. 직접 작성한 파일과 사용자가 제공한 일반 규칙 외의 회사 자료·기존 스킬은 가져오지 않았다.
- 위 검증은 최초 게시 전에 수행했다. 공개 대상은 이번에 작성한 파일들이며 이전 Git 이력은 없었다.

## 확인하지 않은 범위

Windows PowerShell 5.1 실행 정책을 변경하지 않았다. 해당 환경에서는 README의 Python 진입점을 사용할 수 있다.
네이티브 Linux·macOS 실행, Python 3.10 실제 실행, 개인 전역 경로에 실제 설치한 뒤 새 Codex 세션에서 자동 인식하는 과정은 검증하지 않았다.
Git Bash 통과를 네이티브 Unix 검증으로 간주하지 않는다.

비밀정보 패턴 검사와 수동 검토는 모든 민감정보의 부재를 보장하지 않는다.
공개 범위가 바뀌거나 회사 자료·새 Git 이력이 추가되면 그 범위를 다시 확인한다.

## 후속 변경 — GitHub 참고 시점

사용자 요청으로 전역 원본에 ‘개인 Codex kit 참고’ 영역을 추가하고 README·설계 설명을 갱신했다.
기존 원본과 비교해 해당 영역 외의 규칙은 동일함을 확인했다.
사용자가 허용한 현재 PC의 전역 파일에도 같은 영역만 추가했으며, 기존 파일을 로컬 백업하고 원래 바이트를 보존했는지 검증했다.
원본과 설치본에 각각 한 번만 포함되며, 두 파일의 추가 영역이 같은지 확인했다.
개인 경로·백업은 Git에 포함하지 않았다. 설치 스크립트와 스킬은 변경하지 않아 설치기 전체 테스트는 반복하지 않았다.
이 검증은 문서·파일 반영 확인이며, 앞으로 모든 작업에서 원격 조회 시점을 올바르게 선택한다는 행동 검증은 아니다.
