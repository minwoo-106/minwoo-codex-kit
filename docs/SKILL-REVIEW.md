# 스킬 수집 검토 기록

검토일: 2026-10-29. 사용자 제공 조사 자료 네 건을 검토했다.
대화 원문 전체를 다시 조사한 기록은 아니며, 보고서의 실제 사용·부분 사용·요약 근거를 구분했다.
원본 보고서, 대화 제목, 프로젝트 식별자, 로컬 경로, 사업 자료는 공개 저장소에 포함하지 않았다.

반복 언급된 diagnosing-bugs와 plugin-management는 각각 한 번만 셌다.
21st-ai·21st-registry·21st-ui-explore, Figma 관련 항목 등은 언급·설치 상태만으로 실제 사용에 포함하지 않았다.
브라우저·컴퓨터 도구를 실행했다는 사실만으로 computer-use 스킬을 읽었다고 추론하지 않았다.

## 근거의 한계와 결정

- diagnosing-bugs는 사용을 보고한 자료가 있고, 다른 한 자료는 이전 대화 요약만 남아 있었다. 요약만 있는 사례를 원본 호출 확인으로 바꾸지 않았다.
- design-taste-frontend의 일부 문구 관련 활용, 21st-ui-build의 부분 적용은 전체 워크플로 검증과 구분했다.
- 21st-cli-use의 설치·로그인 상태 확인을 검색 결과 가져오기 성공으로 표시하지 않았다.
- studio-review는 작성·검증 및 기반 도구 실행이 보고되었지만, 작성 후 별도 대화에서 스킬을 호출해 끝까지 사용한 근거는 부족했다.
- 공개 저장소에서 codebase-design·prototype의 현재 원본을 찾았다. 자료에서 불명확했던 현재 공개 경로는 보완했지만 과거 설치 커밋은 확정하지 않았다.

## 검수에서 발견한 실질적인 차이

1. **승인 방식:** 현재 tdd 원본은 테스트 경계를 사용자와 확인하도록 명시한다. 일괄 기본 설치에서 제외하고 테스트 우선 작업의 선택지로 둔다. 해당 절차를 전역 AGENTS.md에 복제하지 않는다.
2. **중복 발동:** 디자인 스킬 여러 개가 같은 UI 작업을 넓게 포괄한다. 주도 스킬을 하나 고르고 검색·도구 스킬을 필요에 맞게 보조하는 사용 안내를 마련했다.
3. **실행 의존성:** SKILL.md만으로는 taste-skill의 Node·브라우저 검사, impeccable 실행기, UI/UX 검색 데이터, 21st CLI 기능이 완성되지 않는다. 폴더 전체와 외부 실행 조건을 구분했다.
4. **플랫폼 차이:** ui-ux-pro-max의 Claude용 본문을 Codex에 그대로 복사하는 방식을 제외하고 원본 CLI의 Codex용 생성 경로를 안내했다.
5. **공개 범위:** 프로젝트 전용 영상 검토 스킬은 서버·화면·설정·샘플 없이 배포하면 작동하지 않는다. 의존성이 빠진 SKILL.md를 설치 대상으로 추가하지 않았다.

기존 전역 규칙, 자체 스킬, 설치 스크립트, 승인 설정은 변경하지 않았다.
스킬 수를 늘리기 위한 새 래퍼·자동 라우터·일괄 외부 다운로드 기능도 추가하지 않았다.

## 이번에 확인한 것

- 공개 저장소 6개의 확인 커밋과 11개 SKILL.md, 관련 디렉터리의 파일 목록, 라이선스 파일을 조회했다.
- 원문에서 발동 조건, 사용자 확인 요구, 병렬 에이전트 참조, 외부 실행·다운로드·인증 요구를 검토했다.
- ui-ux-pro-max의 공식 CLI 안내와 Codex 템플릿 경로를 확인했다.
- 현재 제공된 skill-installer 구현에서 --repo·--ref·--path·--dest·--name 인수와 기존 대상 거절을 확인했다.
- 현재 설치된 studio-review에서 프로젝트 의존성을 확인하고, 공개 문서에는 일반화한 목적·의존성·편입 조건만 작성했다.

이번 작업은 문서와 카탈로그 정리다. 외부 스킬의 전체 보조 코드 보안 감사, 모든 실행 도구의 실행 검증,
새 PC 설치, 모델의 실제 스킬 선택 평가는 수행하지 않았다.
소스 커밋 고정은 실행기가 내려받는 바이너리·npm 패키지·외부 서비스까지 고정하지 않는다.

설치기의 기존 테스트 결과는 [검증 기록](VALIDATION.md)에 있고, 이번 문서 변경으로 재실행한 결과처럼 표시하지 않는다.

## 문서 검증

- 변경 문서 4개의 상대 링크 대상 확인: 통과.
- 커밋을 고정한 원본·라이선스·설치 안내 링크 24개와 대응 경로 확인: 통과.
- PowerShell 설치 예시의 구문 분석: 통과. 설치 명령 실행은 하지 않음.
- 공개 대상에서 개인 사용자 경로·프로젝트 식별자·주요 토큰·개인키 패턴 및 내용 수동 검토: 발견 사항 없음.
- 전역 규칙·자체 스킬·설치 코드·테스트·템플릿·버전 파일이 기존 커밋과 동일함을 확인.

문서만 변경했으므로 설치기 전체 테스트를 반복하지 않았다. 민감정보 검사는 모든 비밀정보의 부재를 보장하는 검증은 아니다.
