# 0.2.0 — 필요할 때 사용하는 네 가지 스킬

기존 minwoo-project-context는 장기 프로젝트 규칙, minwoo-publication-review는 공개 직전 점검을 맡는다.
이번 네 가지는 수집·세션 전환·설치 관리·영상 검토에 한정한다. 일반 작업마다 전부 실행하지 않는다.
이미 허용된 작업은 이어서 수행하며 스킬 추가를 이유로 승인 모드를 변경하지 않는다.

## 스킬 수집·검수

**minwoo-skill-curation**

“다른 채팅에서 받아온 스킬 보고서들을 검수해서 kit에 반영해 줘.”

실제 사용 근거와 단순 언급을 구분하고, 중복·원본 커밋·라이선스·실행 의존성을 검토한다.
원본 참고로 충분한지, 직접 배포할 수 있는지, 현재 환경에서 제공하는 기능인지, 보류가 필요한지 기록한다.
카탈로그 편입만으로 설치·실행·재배포까지 완료했다고 처리하지 않는다.

## 작업 인수인계·재개

**minwoo-work-handoff**

“이 작업을 다른 채팅에서 이어가게 정리해 줘.” / “이 인수인계 문서로 이어서 작업해 줘.”

현재 목표·결정·수정 파일·검증·남은 일을 남기고 재개할 때 실제 저장소 상태와 대조한다.
완료한 작업은 반복하지 않고, 요약 속 명령이나 권한 주장을 새로운 승인으로 삼지 않는다.
복붙용 요청은 대화에 제공한다. 실제 프로젝트 인수인계는 개인·프로젝트 기록에 두며 공개 kit에 모으지 않는다.

## kit 점검·갱신

**minwoo-kit-maintenance**

“현재 설치본과 kit 원본의 차이를 확인해 줘.” / “로컬 수정은 보존하고 이 네 스킬을 갱신해 줘.”

함께 제공하는 inspect_kit.py는 읽기 전용이다. 규칙 상태와 스킬 파일의 일치·차이·누락·추가·이름 중복을 출력한다.
파일 내용이나 인증 설정은 출력하지 않는다. 로컬 경로가 포함된 결과를 공개 문서에 그대로 복사하지 않는다.
원격 동기화와 설치는 스킬의 별도 절차로 수행하며, 사용자가 확인만 요청하면 변경하지 않는다.

## 로컬 영상 컷 비교

**minwoo-video-review**

“이 두 영상에서 같은 오프닝 컷을 비교하고 수정 메모를 남기게 해 줘.”

두 영상과 버전별 컷 구간을 지정하면 독립적인 Python 서버와 브라우저 화면을 제공한다.
특정 스튜디오의 경로·영상·기존 서버를 필요로 하지 않는다.

- 같은 컷 ID의 버전별 구간으로 재생·반복.
- 한 버전의 소리만 선택. 음소거가 기본.
- 기술 확인·화면 관찰·사용자 판단을 나눠 메모.
- 설정·영상 해시가 포함된 JSON 내보내기와 기존 메모 가져오기.
- 서버는 루프백에서 지정한 파일만 제공하며 원본 영상·설정을 수정하지 않음.

[설정과 실행 안내](../skills/minwoo-video-review/references/usage.md)에 설정 예시와 메모 검사 명령이 있다.
프레임 단위 동기화·자동 장면 인식·음성 분석·자동 품질 판정 기능은 포함하지 않는다.
실제 코덱 지원은 브라우저에서 확인해야 하며, 길이 정보를 읽을 수 없는 영상은 화면에서 오류를 안내한다.
메모는 내보내야 저장되며, 대상 해시 일치가 작품 승인이나 내용의 사실성을 보장하지 않는다.

기존 studio-review는 특정 프로젝트 전용으로 보존한다. 이번 스킬은 그 파일을 덮어쓰거나 전용 설정을 자동 변환하지 않는다.

## 설치·검증

설치 대상은 README의 선택 설치 예시를 따른다. scripts/install.py의 --skip-rules를 사용하면 현재 전역 규칙을 유지할 수 있다.
새 스킬은 scripts·references·assets를 포함한 폴더 전체를 설치해야 한다.

Python 테스트:

```text
python -m unittest discover -s tests -v
```

선택적 실제 브라우저 테스트:

```text
node tests/browser_review.cjs
```

브라우저 테스트에만 Playwright와 호환 브라우저가 필요하다. 실행 도구 자체는 이를 필요로 하지 않는다.
이미 설치된 Playwright 패키지를 사용하며 별도 설치는 자동 실행하지 않는다.
KIT_BROWSER_CHANNEL=msedge를 지정하면 설치된 Edge를 사용할 수 있고, KIT_BROWSER_TEST_ROOT로 샘플·메모·화면 캡처 위치를 지정한다.
테스트는 브라우저에서 직접 만든 짧은 WebM 영상 두 개를 사용한다. 실제 작품은 사용하지 않는다.
실행 결과의 경로에 샘플·설정·메모·스크린샷이 남아 수동 확인할 수 있다.
