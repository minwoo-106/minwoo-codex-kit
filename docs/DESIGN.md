# 설계와 확인 근거

확인일: 2026-10-29.

## 공통 규칙 보존

사용자가 제공한 전역 AGENTS.md의 11개 영역과 최우선 원칙을 유지했다.
제공 내용과 현재 PC의 전역 파일이 일치함을 확인하고 원본으로 사용했다.
추가한 문장은 두 개뿐이다.

- 이미 허용된 조사·수정·검증은 끝까지 수행하고, 규칙·스킬이 승인 모드나 승인 단계를 임의로 바꾸지 않는다.
- 대화는 친근한 한국어 반말을 기본으로 하고 산출물은 요청·프로젝트 문체를 따른다.

안전 규칙을 스킬마다 복제하지 않는다. 프로젝트 문서에는 프로젝트의 사실만 넣고, 새로운 규칙은 실제 반복된 필요가 확인될 때 추가한다.
권한·실행 정책 설정 파일을 배포하지 않으므로 현재 사용자의 ‘대신 승인’ 모드는 설치 전후 그대로 유지된다.
이는 현재 설정의 동작을 바꾸지 않는다는 의미이며, 이 저장소가 어떤 도구의 승인을 대신 허가하는 것은 아니다.

## 공식 경로와 형식

[공식 AGENTS.md 문서](https://learn.chatgpt.com/docs/agent-configuration/agents-md)에 따라 전역 경로는 `CODEX_HOME` 또는 `~/.codex`를 사용한다.
같은 폴더의 `AGENTS.override.md`가 우선할 수 있다. 프로젝트 지침은 루트에서 작업 경로까지 쌓인다.
문서 합산 기본 한도 32 KiB를 고려해 전역 규칙을 다른 문서에 중복 복사하지 않는다.

[공식 스킬 문서](https://learn.chatgpt.com/docs/build-skills)에 따라 개인 설치 기본값은 `~/.agents/skills`, 프로젝트는 `.agents/skills`다.
`SKILL.md`의 `name`·`description`으로 발견하고 해당 작업에 필요할 때 본문을 읽는 구조를 사용한다.
같은 이름의 여러 스킬을 합쳐 주지 않으므로 중복 설치는 피한다.

현재 PC에서는 기본 Codex 홈과 `AGENTS.md`, 기존 `~/.codex/skills`가 존재했고,
`CODEX_HOME`, 전역 override와 `~/.agents/skills`는 설정되어 있지 않거나 존재하지 않았다.
설정 파일에서는 관련 최상위 경로·승인 키만 확인했으며 해당 키는 명시되어 있지 않았다.
앱의 실제 승인 모드를 파일의 미설정만으로 추정하지 않았다. 사용자 설정은 수정하지 않았다.
로컬 절대 경로나 설정 원본은 저장소로 옮기지 않았다.

공식 문서는 다른 사람에게 배포할 때 플러그인 패키지도 권장한다.
이번 범위는 개인 PC·프로젝트의 규칙과 선택한 스킬을 함께 관리하는 작은 저장소이므로 로컬 폴더 설치로 한정한다.
플러그인 마켓플레이스·훅·자동 라우터는 현재 필요가 없어 추가하지 않았다.

## 참고 저장소에서 채택한 관점

- [cc-plugin README](https://github.com/jongwony/cc-plugin/blob/main/README.md): 행동 원칙과 작업 절차를 구분하고, 절차·코드·참고 데이터를 분리하는 구조를 참고했다. 확인 당시 저장소 메타데이터에는 라이선스가 명시되어 있지 않았다. 본문과 구현은 복사하지 않았다.
- [epistemic-protocols README](https://github.com/jongwony/epistemic-protocols/blob/main/README.md): 모든 절차를 항상 강제하지 않고 필요한 판단 상황에 맞춰 선택하는 관점을 참고했다. 확인 당시 MIT로 표시되었으나 이번 구현에는 원문이나 코드 복사본이 없다. 대화마다 사용자 결정을 요구하는 절차나 실험적 훅은 가져오지 않았다.

참고 자료는 설계 근거이며 현재 사용자의 지시나 설치 권한을 확장하지 않는다.

## 설치와 갱신

원본 저장소가 수정의 기준이고, 설치본은 복사본이다. 링크 설치는 경로·Windows 권한 차이를 줄이기 위해 사용하지 않는다.
선택한 파일의 SHA-256을 로컬 상태에 기록해 기존 내용·사용자 편집·관리 중인 파일을 구분한다.
선택한 파일 전체의 충돌을 먼저 검사하고, 승인된 교체와 정상 갱신 모두 교체 전 백업을 만든다.
반복 실행은 파일과 상태 내용이 같으면 쓰지 않는다. 실패 복구는 이번 실행에서 쓴 파일에 한정한다.

전역 상태와 백업은 전역 규칙 옆, 프로젝트 상태와 백업은 프로젝트 내부의 `.minwoo-codex-kit/`에 둔다.
다른 스킬이나 파일을 삭제하지 않고 `config.toml`·인증·승인 설정도 수정하지 않는다.
자동 네트워크 갱신 대신 사용자가 원본 Git 변경을 확인하고 `git pull --ff-only` 후 같은 설치 명령을 실행한다.
