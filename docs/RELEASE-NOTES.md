# 0.5.0

- 웹 동작 검사와 API 계약 호환성 스킬을 추가했다.
- 기존 diagnosing-bugs를 MIT 고지와 함께 관리 대상으로 편입하고 GitHub Actions 실패 조사 안내를 확장했다.
- 기존 영상 검토에 납품 규격·음성 스트림·SRT 검사, PostgreSQL 검토에 격리 DB 변경·복구 연습을 추가했다.
- 기존 유지보수 스킬에 발견 목록 크기·중복 점검을 추가했다. 실제 토큰 수와 호스트 노출 여부는 별도라는 한계를 명시했다.
- 실제 브라우저·영상·DB·API의 정상/결함 시험 8개와 새 Codex 세션의 결과물 시험을 추가했다. GitHub CI에서도 도구 실행 시험을 수행한다.
- 배포 스킬은 17개이며, 이 PC에 새로 생기는 스킬은 2개다. 디버깅 스킬은 기존 같은 이름 폴더를 확장했다.
- 기존 승인 설정·전역 규칙·다른 플러그인은 유지한다. 검증 결과와 재시험은 docs/VALIDATION.md에 구분해 기록한다.

## 0.4.0

- 14개 스킬을 core/web/video/documents/all 묶음으로 선택 설치할 수 있다. 기존 규칙 보존·충돌 감지·반복 설치 동작을 유지했다.
- 읽기 전용 doctor로 설치 차이·중복·도구 상태를 확인한다. 유지보수 비교에서 실행 캐시를 제외했다.
- 실제 Codex 스킬 선택 21개 사례와 증거 기반 평가기를 추가했다. 결과와 평가 범위는 검증 기록에 남긴다.
- Windows/macOS/Linux 자동 검사와 선택 도구 실행·의존성 감사를 추가했다.
- Dependabot 갱신 PR을 구성했다. 자동 병합이나 PC 자동 업데이트는 하지 않는다.
- 버전 태그의 검사 통과 후 ZIP·SHA-256·커밋 정보를 Release로 제공한다. 복구 절차를 문서화했다.
- 사용자 승인 방식, 모델 설정, 전역 규칙을 변경하지 않는다.
