# studio-review — 프로젝트 의존성을 정리할 후보

상태: **기존 프로젝트 전용 스킬은 보존 / 범용 도구 별도 구현**. 검토일: 2026-10-29.

후속 작업으로 [minwoo-video-review](../../skills/minwoo-video-review/SKILL.md)를 직접 구현했다.
로컬 서버·비교 화면·메모 해시 검증을 함께 제공하며 특정 프로젝트의 서버·코드·영상은 가져오지 않았다.
기존 studio-review를 교체하거나 전용 설정을 변환하는 마이그레이션은 아니다. 아래 내용은 최초 후보 조사 기록이다.

사용자 제공 자료에서 직접 작성·검증했다고 보고한 영상 검토 절차다.
현재 로컬 본문에서도 전용 서버·설정 문서 의존성을 확인했다.
개별 프로젝트 이름·경로·영상·메모·해시는 공개하지 않았다.

## 재사용할 가치가 있는 부분

- 이미 만든 영상의 특정 컷을 반복해서 보고 버전 간 변경을 비교한다.
- 전체 영상의 같은 시간 대신 각 버전의 같은 컷 ID와 컷 구간을 비교해 길이 변경에 따른 어긋남을 피한다.
- 메모의 영상·설정 해시가 실제 검토 대상과 맞는지 확인한다.
- 기술적인 재생 성공, 화면에서 확인한 사실, 사용자의 작품 판단을 구분한다.
- 화면을 열었다는 이유로 청취·작품 승인까지 완료했다고 보고하지 않는다.

새 영상 제작·외부 생성·새 렌더는 이 후보의 기본 범위에 포함하지 않는다.
이미 실행 중인 로컬 검토 서버가 있다면 재사용하는 절차를 유지한다.

## 빠져 있는 실행 의존성

다음은 제공 자료와 현재 스킬 본문에 나타난 인터페이스다.
실제 소스 파일을 이번 kit에 가져오거나 전체 구현을 검증하지 않았다.

| 필요한 파일·환경 | 역할 |
| --- | --- |
| 프로젝트 AGENTS.md | 해당 영상 작업의 규칙 |
| docs/operations/STUDIO_CURRENT.json | 현재 영상·설정 대상 |
| docs/operations/STUDIO_REVIEW.md | 검토 서버 실행 안내 |
| scripts/studio_review.py | 로컬 검토 서버 |
| tools/studio_review/index.html | 반복 재생·버전 비교·메모 화면 |
| tests/studio_review/test_studio_review.py | 검토 도구의 회귀 검증 |
| 영상·컷 구간 설정·메모 형식 | 비교와 해시 검증의 실제 데이터 |
| Python 3.11 이상 | 제공 자료가 hashlib.file_digest 사용을 보고함. 실제 코드 확인 필요 |

서버·화면·설정 형식 없이 SKILL.md만 새 PC에 옮기면 작동하지 않는다.
따라서 이 문서는 발견 가능한 skills/ 밖에 두고 YAML 스킬 머리말도 넣지 않는다.

## 설치 가능한 스킬로 승격할 조건

1. 서버·화면·설정 인터페이스의 소유권과 공개 가능 범위를 확인한다.
2. 프로젝트 이름이나 고정 경로 없이 사용자가 지정한 프로젝트 루트를 입력으로 받도록 한다.
3. 실제 작품·회사 자료 대신 직접 만든 중립적인 샘플 영상·설정으로 비교 기능을 검증한다.
4. 필요한 코드·참고 문서·라이선스를 함께 제공하고 로컬 주소 바인딩, 파일 접근 범위, 메모 저장과 해시 검증 동작을 확인한다.
5. 격리 환경에서 서버 시작·재사용, 컷 반복, 버전 비교, 메모 저장, 잘못된 대상 거절을 검증한다.
6. 새 대화에서 스킬을 실제로 호출해 독립적으로 사용 가능한지 확인한 후 배포 대상으로 추가한다.

이번에는 후보의 목적과 편입 조건만 정리했다. 실행 코드와 테스트를 새로 구현한 상태가 아니다.
